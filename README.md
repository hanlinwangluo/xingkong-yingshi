## 🛠 安装说明

### Android 手机 / 平板
1. 下载「手机版」APK 文件
2. 点击安装，若系统提示未知来源，请允许本次安装
3. 安装完成后打开即可使用

### 安卓电视 / 电视盒子
1. 下载「TV版」APK 文件（可用 U 盘拷贝，或通过局域网/网盘传输）
2. 在电视上点击 APK 文件进行安装
3. 安装完成后从应用列表进入「星空影视」

> 推荐 Android 版本：Android 6.0 及以上（TV 版建议 Android 7.0+）。

## ❓ 常见问题（FAQ）

**Q：安装时提示「未知来源」怎么办？**
A：进入系统设置 → 安全/应用 → 开启「允许安装未知来源应用」，或直接在弹窗中选择「仍要安装」。

**Q：手机版和 TV 版可以同时装吗？**
A：可以，两者相互独立，分别安装于不同设备即可。

**Q：安装后打开闪退？**
A：请确认设备 Android 版本满足要求，并检查是否下载了对应设备的最新版本。

- 播放暂停逻辑优化：只有打字发弹幕、返回上一页、切到后台才暂停，全屏切换、截图等不再误暂停
